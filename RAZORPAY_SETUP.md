# Razorpay integration — test candidate
Based on Hajara_Source.zip. Existing certificate code retained. This is not a production-certified payment release.

Render: set RAZORPAY_KEY_ID and RAZORPAY_KEY_SECRET to test credentials; set DEMO_PAYMENTS=false; set RAZORPAY_WEBHOOK_SECRET to a new strong random secret. APP_PUBLIC_URL=https://hajarailmacademy.pages.dev. Keep existing Brevo and database configuration. Flyway V20 creates razorpay_orders. Configure Razorpay automatic capture and a TEST webhook at https://hajara-ilm-academy-backend.onrender.com/api/payments/razorpay/webhook with the same webhook secret and payment.captured and refund.processed events. Never commit secrets. Test deployment on a separate database/service first.

Registration verifies email, then creates an order at server-side batch price. Captured payment is checked via Razorpay API before account creation. Webhook and checkout callback use HMAC verification. Receipt PDF is sent via existing Brevo API, with manual admin retry. Admin Payments displays gateway-reported fee (inclusive of GST), tax and estimated net, not actual bank settlement. Student Certificates page also lists payment receipts. No academy GST tax invoice is generated. Refund amounts are informational; refunds and access revocation require manual review. Failed or abandoned orders remain pending; reconcile in Razorpay dashboard. If a captured payment cannot enroll (duplicate account or deleted batch), reconcile manually and refund if appropriate. No automatic refund initiation. No automated receipt retry scheduler. Checkout does not collect billing address or GSTIN. Legacy database columns remain for compatibility; new orders store empty values. Receipts omit addresses. Receipt font is Latin-only. Pending records retain password hashes until successful enrollment; establish retention/cleanup before production. Do not use live keys until reviewed and tested.

Build locally: backend `mvn clean verify`; frontend `npm ci && npm run build`. Test valid capture, forged signatures, wrong amount, repeated webhook, browser closed before callback, duplicate registration, email delivery failure and retry, refunds, student receipt access isolation, and certificate regression. Build and live gateway tests were not run in the artifact environment. Actual settlement reconciliation and tax compliance require further work.
